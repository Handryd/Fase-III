# Sistema de Administración de Productos

Proyecto integrador para crear un sistema que administre productos, precios y usuarios para un negocio familiar.

## Funcionalidades principales
- Registro y edición de productos
- Consulta de precios por nombre o categoría
- Control de acceso por usuario
- Integración con Trello y Travis CI

## Tecnologías utilizadas
- Java
- GitHub
- Trello
- Travis CI
